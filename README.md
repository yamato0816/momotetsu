# レールトリップ 🚆

**友達と最大4人で対戦できる、オリジナルのブラウザ鉄道すごろく**。既存の桃太郎電鉄の画像・音源・ソースは使っていません（非公式・無関係）。

- **全国36駅を路線グラフで結ぶ見下ろしマップ**。サイコロを振ったら、残りマス数だけ隣接駅をタップして自由に進路を選ぶ（分岐・折り返しあり）
- 目的地に到着すると **1,100万円** のボーナス、次の目的地が決まる
- 各街に **2〜4件の名前・価格・収益率が異なる物件**。チェックで複数選択して一括購入。1駅の物件を独占するとその駅の年収が **2倍**（通行料はなし）
- イベントマスには臨時収入・出費。ショップで特急きっぷ（出目+2）やおまもり（損失イベント防止）を購入
- **6年（短め）または10年**を選択し、終了時の総資産（現金+所有物件の購入価格）で順位を決定
- 部屋コード / 招待リンクで2〜4人、WebSocketで同時対戦、リアクション機能付き
- プレイヤー別所持金・総資産の大きな表示、到着駅の選択、ルート強調、駅アイコン、サイコロ・移動・収益のアニメーション
- モバイルで地図を左右スクロール・拡大縮小・現在地へ移動。ログイン・DBの別途契約不要

## 構成

| ファイル | 内容 |
| --- | --- |
| `public/` | 依存ライブラリなしのHTML/CSS/JSクライアント |
| `src/index.js` | Cloudflare WorkerとDurable Object（部屋・認証・WebSocket） |
| `src/game.js` | サーバー権威のゲームルール（テスト可能な純粋JS） |
| `wrangler.jsonc` | Cloudflare Worker Static Assets + SQLite-backed Durable Objectの設定 |
| `tests/` | ゲームルールの単体テスト |

**通信イメージ**：ブラウザ → HTTPS/WebSocket → Cloudflare Worker → 部屋ごとのDurable Object（SQLite永続ストレージ）。サイコロ・購入・所持金・勝敗は必ずサーバー側で判定し、ブラウザから数値を改変できません。

## ローカルで試す

Node.js 20.18+ または 22+ を推奨。Cloudflare のアカウントなしでも開発サーバーでテストできます。

```bash
npm install
npm test
npm run dev
```

Wrangler が表示したURL（通常 `http://localhost:8787`）をブラウザで開きます。ブラウザのシークレットウィンドウ、または別端末の独立したブラウザで別プレイヤーとして参加できます。`localhost` はそのPCだけでアクセスできるため、外部の友達と遊ぶときはデプロイが必要です。

## Cloudflareに公開する

CloudflareアカウントでログインできるPCで以下を実行してください。

```bash
npm install
npx wrangler login
npm run deploy
```

表示される `https://railtrip-friends.<subdomain>.workers.dev`（実際のURLは環境による）を開き、部屋を作成して招待リンクを共有します。Workers FreeでもSQLite-backed Durable Objectsを利用できますが、リクエスト数・ストレージ等の無料枠上限があります。請求設定や利用状況はCloudflareダッシュボードで確認してください。

## 遊び方

1. ホストが名前を入力して「新しい部屋をつくる」を選択。
2. 招待リンクを友達に共有。友達は名前を入力して部屋に参加。
3. ホストが6年/10年を選び、**全員オンラインで2人以上**ならスタート。
4. 自分の番でサイコロを振ると **進路選択モード**になります。黄色く光る隣接駅を地図でタップするか、右側の駅ボタンで1マスずつ移動します。残りのマス数を使い切るか目的地に到着すると停止します。
5. 物件駅では購入したい物件にチェックを入れ、合計金額を確認して **一括購入**。ショップではアイテムを1点購入。何も買わない選択もできます。
6. 参加人数分のターンが終わると次の年へ。最終年後、総資産の一番多い人が優勝。

ログイン不要のため、同じ端末・ブラウザの`localStorage`に保存した匿名IDと認証トークンで復帰します。端末のデータを消したり、別のブラウザで同じ招待リンクを開くと別プレイヤーとして扱われます。部屋が満員・ゲーム開始済みなら新規参加できません。対戦中に切断されたプレイヤーの順番は他の参加者がスキップ可能です。

## 公開前の留意点

- この版は友人同士の**招待コード制MVP**。公開インターネット向けのレート制限、BOT防止、管理画面は未実装です。大量アクセスが想定される場合はCloudflare側のレート制限やTurnstileを追加してください。
- ルームには削除期限（TTL）を設定していません。長期運用時はDO Alarmによる古い部屋の自動削除を追加してください。
- 物理的な位置関係はゲームの見やすさを優先した模式図で、鉄道路線・地理的な正確さを表すものではありません。

## v2 アップデート（平面マップと経営UI）

- 駅は一本道ではなく、東京から北陸・東海道・東北・千葉方面、関西から山陽・四国方面などに自由に進路を分けられます。次の駅は必ずサーバーで接続関係を検証し、ジャンプなどの不正移動を防止します。
- 金額の内部単位は万円。画面では1億円を超えた額を「○億○万円」で表示。所持金、物件件数、総資産、毎年の見込み収益を区別します。
- 既存のv1部屋は最初の再接続時にv2形式へ変換します。旧ターンの途中状態だけリセットし、名前・現金・物件（各旧駅の代表1件へ割当）を維持します。
- 桃鉄の既存キャラクター、マップ素材、音楽、具体的な画面デザインは複製せず、遊びやすさとすごろくの手触りを意識したオリジナルUIです。
