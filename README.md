# レールトリップ v3 🚂🗾

友達2〜4人とブラウザで対戦する **日本縦断・鉄道経営すごろく**。完全オリジナルの駅・物件・カードです。『桃太郎電鉄』とは非公式・無関係で、同作の画像・音源・コードは使っていません。

## 遊び方

1. ホストが部屋を作り、6桁コードか招待リンクを共有（2〜4人）。
2. 自分のターンでサイコロを振り、**列車の周囲に出る矢印**を押して隣の駅に1マスずつ移動。方向は毎マス選べます。
3. 地図は**自分中心の拡大表示**。右上ミニマップで現在地と目的地を確認。右上の「全体マップ」を切り替えることもできます。
4. **目的地にぴったり到着**（残りマスが0で到着）すると1,100万円獲得。多すぎる出目では通過するため、迂回や「ぴったりカード」が重要です。
5. 物件駅では買いたい店を複数選んで購入。年間収益が発生し、駅を独占すると年間収益2倍。
6. **海路**（青の破線：1回80万円）と**空路**（紫の破線：1回240万円）は移動マスを節約できます。空路は空港へ行く必要があります。
7. **カード駅**でランダムにカード獲得、**ショップ駅**で購入。手札上限8枚。カードはサイコロ前に使用できます。
8. 目的地に到着した人が出ると、到着者以外で新目的地から最も遠い人に**貧乏神**が取りつきます。所持者のターン終了時にお金が減ることがあります。駅で他人と接触すると貧乏神が移ります。
9. 6年または10年の最後に**現金＋物件の購入額**で資産王を決定します。

### カード

| カード | 効果 |
|---|---|
| 特急カード | 次の移動+2マス |
| 新幹線カード | 次の移動+4マス |
| ぴったりカード | 次のサイコロを1に固定 |
| 研究費カード | +400万円 |
| 単位取得カード | 損失イベントまたは貧乏神の出費を1回防止 |
| ぶっとびカード | ランダムな物件駅へ飛び、そのターンを終了 |

カード効果、購入、移動先、料金はサーバー側で検証されるため、ブラウザからお金を操作して不正行為はできません。

## 技術構成

- **Cloudflare Workers**: 静的サイト配信・APIエントリ
- **Durable Objects (SQLite)**: 部屋単位のゲーム状態保存、WebSocket一斉配信
- **バニラ HTML/CSS/JavaScript + SVG**: スマホ・PCでの路線マップとUI
- **Node.js test runner**: グラフ・移動・カード・貧乏神・所有権・旧部屋互換を検証

## セットアップ・デプロイ

```bash
npm install
npm test
npm run check
npx wrangler login
npm run deploy
```

既存の Cloudflare Worker に同名 `railtrip-friends` として更新デプロイされます。古い部屋データは v3 に変換されます（進行中の選択操作のみ安全のためリセット）。Workers / Durable Objects を無料プランで利用する場合も利用上限は Cloudflare の現行料金表を確認してください。

### ローカル開発

```bash
npm run dev
```

ブラウザで Wrangler の開発用 URL（通常 http://localhost:8787）を開きます。別タブか別ブラウザで2人以上接続するとマルチプレイ動作を確認できます。

## 現時点の制限

- 地図は2Dの模式図で、線路と駅の実際の地理・運行情報とは一致しません。
- ブラウザのページを閉じた場合はローカル保存した ID により同じプレイヤーとして再接続します。
- デプロイ前後の新旧版のゲーム画面が混在すると動作がおかしくなる場合があります。全員が再読込してください。
